# Accessibility

Career Track targets WCAG 2.2 AA. The five V4 screens use semantic landmarks, visible focus, keyboard shortcuts, native controls and text-labelled status. The detail drawer traps focus, closes with Escape and restores focus. Reduced motion is respected; countdown seconds do not continuously announce to screen readers.

Keys 1–5 switch primary views; `/` focuses search. Tabs use arrow keys and Home/End. Calendar cells use arrows and Enter; `T` returns to today. Mobile uses a bottom navigation rail and an agenda calendar. Native select/date popups follow the browser and operating system.

Automated Axe checks report no serious/critical issues on all five views in both themes. Browser tests cover widths 320–1440, keyboard operation, storage failures and recovery. This is not a claim of a formal accessibility certification or testing on every assistive technology. Report a reproducible issue through the repository’s issue tracker without including private application data.
