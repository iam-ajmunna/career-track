The 17 browser scenarios exercise application functionality; compilation alone is not the acceptance gate. Raw UI strict-audit findings are retained: five literal-button findings are false positives from the inline-handler-only scanner, resolved against shared document delegation and browser flows in `ui-reviewed-audit.json`. No CSP weakening or inline event handlers were added. DESIGN.md lint reports zero errors and nine pre-existing runtime-token-document ownership warnings.

Remaining limits: coverage is curated; many legacy/current-cycle requirements and student accounts are unverified; some official sources conflict or cannot be retrieved; external applications/visa decisions/funding offers require provider confirmation. Source monitoring does not automatically verify factual changes. Live FX, cross-device sync and personal out-of-browser push notifications are not configured. The owner must import personal context on the browser holding private progress; deployment cannot access that browser's localStorage.
